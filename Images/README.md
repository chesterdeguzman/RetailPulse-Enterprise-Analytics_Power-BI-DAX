# Portfolio Images

These images are presentation-ready dashboard design mockups generated from the synthetic data included in this repository.

They demonstrate the intended visual direction for the Power BI report and may be used in this GitHub README, a portfolio website, or a case study.

> Note: These are static design mockups, not exports from a live Power BI report. The interactive canvas must still be assembled in Power BI Desktop.
