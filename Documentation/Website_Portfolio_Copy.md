# RetailPulse Enterprise Analytics

## Project summary
RetailPulse Enterprise Analytics is an end-to-end business intelligence portfolio project for a fictional omnichannel retailer. It combines a star-schema semantic model, Power Query transformations, 42 DAX measures, SQL analytics, source-controlled PBIP/TMDL files, and executive dashboard design mockups.

## Business challenge
Leadership needed a unified view of revenue, profit, customer value, product performance, regional results, budgets, and returns. The project consolidates eight analytical tables into a reusable reporting model designed for executive and operational decision-making.

## What I built
- 42,000 synthetic transaction records across 2023–2025
- Eight-table analytical model
- 42 DAX measures covering time intelligence, growth, customer, product, returns, and targets
- SQL schema and business analysis queries
- Automated local data-path configuration
- GitHub Actions validation workflow
- Four portfolio-ready dashboard design mockups

## Tools
Power BI, DAX, Power Query, SQL, PBIP/TMDL, Git, GitHub, Python, and Excel.

## Portfolio note
The screenshots in this repository are static design mockups created from the project dataset. The source-controlled model, DAX, SQL, data, documentation, and theme are included. Power BI Desktop is required to assemble and render the final interactive report canvas.
