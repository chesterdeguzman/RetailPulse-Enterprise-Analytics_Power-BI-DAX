# Portfolio Case Study

## Business problem
RetailPulse leadership needed a single view of revenue, profitability, customer behavior, product performance, returns and regional budget attainment.

## Solution
Built a source-controlled Power BI project with a star schema, 42 DAX measures, reproducible CSV sources, SQL analysis examples, automated local path configuration and enterprise-style dashboard specifications.

## Dataset
42,000 order lines, 2,500 customers, 40 products, 12 regions, 24 employees, three calendar years, monthly budgets and realistic returns. All names and transactions are synthetic.

## Skills demonstrated
Power BI, DAX, Power Query, TMDL, PBIP, dimensional modeling, SQL, Git/GitHub, documentation, KPI design and business storytelling.
